# The Pattern Machine — Content v1 (MA.4.5B-XP)

**Grade 4 · Math · Mechara.** Written Sept 28, 2026. Code: `lib/cases/expedition-station/quests/pattern-machine.js`.

**Main standard:** 4.5B · **Also shows up under:** 4.5A

**I can:** I can use a rule and an input-output table to make a number pattern, find the value at any position, and write equations with a letter for the unknown.

**Mission:** Crack the rules of the robot assembly lines and keep every machine building the right number of robots.

**Story:** The robot assembly lines of Mechara follow secret number rules. The crew needs help cracking each rule so the lines can build the right robots at every spot.

**Meters on Mechara:** Line speed (starts at 10%) · Rules cracked · Journal (10 discoveries)

**Status:** All 3 acts are playable. Every task is graded (written answers are scored by the teacher).

**Opening (Vega):** Specialist {firstName}, this is Commander Vega. We've landed in the robot city on Mechara. Every assembly line here follows a number rule. The rule turns each spot's position into a value. The rules got scrambled, and the lines are slowing down. Help Kai and Nova crack them. Vega out.

## Discoveries (Earth-true)

| Task | Discovery | Fact |
| --- | --- | --- |
| 1 | Robot safety | Many factory robots work behind fences or invisible light beams called light curtains. If a person steps through the beams, the robot stops right away. |
| 2 | Computers count with 0 and 1 | Computers store numbers, words, and pictures using only two digits, 0 and 1. This is called binary. |
| 3 | Morse code | Morse code spells out letters with a pattern of short and long signals called dots and dashes. The letter S is dot, dot, dot. |
| 5 | Salt crystals | Grains of table salt are tiny cube-shaped crystals. Inside, the salt particles line up in a pattern that repeats again and again. |
| 6 | Barcodes | A barcode is a pattern of black bars and white spaces. A scanner reads the pattern and turns it into numbers. |
| 8 | Loom cards | Over 200 years ago, a weaving machine called the Jacquard loom used cards with punched holes to weave patterns into cloth. That idea helped inspire early computers. |
| 10 | Cricket thermometers | Crickets chirp faster when it's warm and slower when it's cool. By counting their chirps, you can make a good guess of the temperature. |
| 11 | Spider web patterns | Orb-weaver spiders spin webs with straight spokes and a spiral that loops around and around in an even pattern. |
| 13 | Sunflower spirals | The seeds in a sunflower head grow in spirals. One set of spirals curves one way, and another set curves the other way. |
| 15 | Zebra stripes | Every zebra has its own stripe pattern. No two zebras have stripes that are exactly the same. |
