# Maker Studio visual reference

The approved references are Inventor’s Lab (teal illuminated workstation in a navy/violet space station), the simple Make a poster editor, and the Teach the Buddy / Paint what I said / What if / Postcard screen sheet.

Preserve these layout requirements:
- Artwork is the main surface, not one card in a long form.
- Desktop editor, right mission/progress panel, and Save/Done footer fit together in the viewport.
- Slim left Pictures, Draw, Text rail. Picture library searches the existing catalog and opens beside the rail.
- Ivory/lavender surfaces, deep purple typography, teal active borders and primary buttons.
- Keep activity instructions short; avoid repeated mission text and nested heading cards.
- Complex modes may scroll inside the work area; Save and Done stay outside that scroll area.
- Mobile may stack panels while retaining accessible actions.

The collage shown in the Inventor’s Lab concept is illustrative. The current poster model stores one image/drawing plus title and caption; do not suggest it supports movable collage layers. Existing art must not be duplicated to imitate a screenshot.

Validate new visual changes against the actual reference images, not only successful compilation. Check desktop layout and functional picture selection, editing, save, Done and mode switching before declaring a revision ready.
