# Frequency Rush — ELAR Word Study Sets · Review v1

*Sept 24, 2026. 12 sets, 360 questions, drafted by Claude for Emily's review as author of record. The design is §11.5 of `FrequencyRush_Fluency_Expansion_v1.md`.*

**How to review:** each table lists the question, the right answer (**bold**), the wrong choices and the explanation a student sees after answering. The site shuffles the choices. To change something, tell Claude the item number (for example `ela4hom:05`) or edit the set file in `lib/cases/frequency-rush/skills/`. Then run `node tools/frequency-rush-skillcheck.cjs`.

**Every set passed the checker:** 30 items each, 3–4 unique choices, the answer among them, an explanation on every item, and no sentence over the grade's word limit (16 / 21 / 25 words for grades 3 / 4 / 5). Every TEKS code was checked against the ELAR PDF before writing.

**Choices worth your eye:**

- **3.11D (Parts of Speech):** the standard is about editing drafts. About 20 of the 30 items ask students to *name* the part of speech, which supports that editing but is one step away from it. The other 10 have students pick the correct form.
- **5.11D (Grammar Fix-Ups):** every item asks the same question, "Which sentence is written correctly?" Each wrong choice has exactly one error.
- **5.2B (Spelling Changes):** the wrong spellings are made-up near misses, like *selecsion*.
- **4.9B (Figurative Language):** the set adds two *literal* lines so students can't guess that every line is figurative.
