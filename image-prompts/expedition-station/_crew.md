# Expedition Station crew — image requests

These three portraits appear in every Expedition Station quest (all subjects, all planets). The student screen shows them as round avatars next to each crew line, so keep the face centered with space around it — the edges get cropped to a circle. Until a file exists, the screen shows a colored initial badge instead, so nothing breaks while these are pending.

Make all three in one sitting so they look like the same crew: same art style, same lighting, same uniform design (only the accent color changes).

**Shared style for all three:** friendly cartoon portrait in the soft crystal sci-fi house style, head and shoulders, facing the viewer with a warm, calm smile. Clean rounded shapes, soft shading, gentle glow. Each wears the same crew uniform: a white and lavender flight jacket with a small glowing crystal badge on the chest. Plain soft pastel background in the character's accent color, fading to white at the edges. Kid-friendly for Grades 3–5. No text, letters, logos, or known characters.
