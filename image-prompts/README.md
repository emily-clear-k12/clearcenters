# Image prompts

Content writers put image requests here. An image bot (or a person) reads each request, makes the image, saves it at the **Save to** path, and checks the box.

## How a request file works

- One file per activity or quest, grouped in a folder per center (for example `expedition-station/glow-garden-harvest.md`).
- Each image has: a **Save to** path under `public/`, a size, the prompt, and a status box.
- The code already points at the **Save to** path, so an image appears on the site as soon as it's saved there with that exact name. Don't rename files.
- When an image is done, change `- [ ] Made` to `- [x] Made`.

## House style (all ClearCenters art)

Soft crystal sci-fi, matching the live center cards: bright, clean, pastel lavender, white, and teal with glowing crystal accents; friendly and calm; no text or letters in the image; no real brands, logos, or known characters; kid-friendly for Grades 3–5.
