# Exhibit Hall case list

**Updated Sept 24, 2026.** Check this file before writing a case. One case per standard. If the code is already **Built** or **Next**, do not write it again.

The long idea bank is `MakerStudio_Exhibit_Table_of_Possibles.md` (60 rows). This file is the status list.

## Rule

- Science codes have no prefix: `3.13A-EX`.
- ELAR codes use `ELA.` and Social Studies codes use `SS.`, so `ELA.3.8A-EX` is not the same case as science `3.8A-EX`.
- The live engine is a **four-spot wall**. Each spot is one job. A card is right if its job matches that spot. One myth. One late note. Photos, short text, or a bar graph.
- Side-by-side, timeline, portrait, and math-model cases are **Later**. Do not force them onto this wall.
