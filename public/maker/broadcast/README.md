# Broadcast Booth chip art

Kid-facing picture chips for Field Radio / Desert Radio brainstorm maps.

These files are under `public/maker/broadcast/` so Maker Studio living library scan picks them up (see `public/maker/README.md`).

**Photoreal documentary photos** (classroom-safe) — not cartoon icons, not Soft Crystal toy radio chrome for content chips. Tiny captions stay on the chips in the UI.

Prefix: `bb-` = Broadcast Booth.
