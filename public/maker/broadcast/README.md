# Broadcast Booth chip art

Kid-facing picture chips for Field Radio brainstorm maps (Explain / Correspondent / Debate).

These files are under `public/maker/broadcast/` so Maker Studio living library scan picks them up (see `public/maker/README.md`).

**Photoreal documentary photos** (classroom-safe) — not cartoon icons, not Soft Crystal toy radio chrome for content chips. Tiny captions stay on the chips in the UI.

Prefix: `bb-` = Broadcast Booth.

Seeds:
- Desert Explain (`SCI.3.13A-BB`) — cactus / adaptations chips
- Creek Correspondent (`SCI.3.12B-BB`) — creek bank / habitat chips
- Schoolyard Debate (`SCI.3.11B-BB`) — shade trees vs playground chips
- News Desk (`ELA.3.9D-BB`) — garden barrel chips for central idea and evidence
