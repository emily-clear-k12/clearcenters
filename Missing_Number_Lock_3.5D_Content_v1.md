# The Missing Number Lock — Content v1 (MA.3.5D-XP)

**Grade 3 · Math · Cindara.** Written Sept 28, 2026. Code: `lib/cases/expedition-station/quests/missing-number-lock.js`.

**Main standard:** 3.5D · **Also shows up under:** 3.5C, 3.5E

**I can:** I can find the missing number in a multiplication or division equation. I can use fact families, describe times-as-many comparisons, and fill in number-pair tables.

**Mission:** Find the missing numbers, open every vault door, and reach the master vault before the lava does.

**Story:** Deep in the lava rock of Cindara, the Magma Vaults are locked tight. Each vault door opens only when the crew finds the missing number in a multiplication or division equation.

**Meters on Cindara:** Vault power (starts at 20%) · Vaults opened · Journal (10 discoveries)

**Status:** All 3 acts are playable. Every task is graded (written answers are scored by the teacher).

**Opening (Vega):** Specialist {firstName}, this is Commander Vega. We've reached the Magma Vaults on Cindara. The vault doors are locked with number codes. Each keypad shows a multiplication or division equation with one number missing. Help Kai and Nova find each missing number and open the vaults. Vega out.
