# SS-3-2A — Why Communities Form

## Official standard text (current, 2022-adopted TEKS)

> Identify reasons people have formed communities, including a need for
> security and laws, religious freedom, and material well-being.

Verified against the current Texas Administrative Code text (19 TAC §113.14,
Social Studies Grade 3), not just a snapshot PDF — see the caveat in this
folder's README about a stale mirror found on the 3.2B side.

Matches the `teksText` already in `lib/briefings/SS-3-2A-BR.public.js`
almost verbatim (that file drops "have" — "form" vs. "have formed" — a
harmless simplification, not a substantive difference).

## STAAR classification (from lead4ward's Grade 3 Social Studies TEKS
Snapshot, retrieved via a district mirror — lead4ward.com itself blocks
direct fetching)

- Reporting Category 1 — History
- Classification: Supporting Standard
- Process standard connection: 3.17(B) — sequence and categorize information

## The three sub-parts (this is the checklist a lesson must actually teach,
practice, AND test — see `scripts/briefings-checker.js`)

1. Security and laws
2. Religious freedom
3. Material well-being

## Vocabulary

community, security, laws, religious freedom, material well-being

## Notes for an AI generation pass

- **teksguide.org does not cover Social Studies** (confirmed directly —
  its subject list is ELPS/ELAR/Science/Spanish Language Arts/Tech
  Applications only), so there is no misconceptions/vertical-alignment
  page to pull from for this standard the way there is for Science. The
  existing SS-3-2A-BR content's misconception framing ("material
  well-being just means having toys → false; it's needs like food, homes,
  jobs, goods") came from Emily's own authoring, not a sourced reference —
  worth treating as a genuinely useful example brief for future SS
  standards even without an external misconceptions source to lean on.
- A grade-3-appropriate way in is concrete, visible community features
  (firefighters/speed-limit signs for security & laws; a place of
  worship for religious freedom; a market/farm/jobs for material
  well-being) rather than the abstract vocabulary itself — this is what
  the existing lesson already does well.
